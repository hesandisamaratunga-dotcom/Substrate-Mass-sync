# Substrate-Mass-sync

All rights reserved to MycoLutions GmbH.

This repository contains the scripts and the workflows I wrote and developed to schedule the the substrate mass sync from an existing Excel sheet to the IoT platform :Datacake.

There are 2 python scripts. Both feeds the timestamp and the substrate mass columns to the dashboard.
-Backfill.py : Manually pushed once. All the past data was fed. 
-Fetch Substrate Mass : Feeds data everyday scheduled at 12pm (10:00 UTC = 12:00 CEST (German summer time)
